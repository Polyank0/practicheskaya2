# Граф зависимостей пакетов Ubuntu. Вариант №27

Практическая работа №2 по дисциплине «Конфигурационное управление».

Состояние: выполнен этап 3 из 5 (основные операции).

## Общее описание

Консольная программа для анализа зависимостей пакетов Ubuntu (apt).
Менеджеры пакетов и сторонние библиотеки не используются: описание
пакетов скачивается и разбирается средствами стандартной библиотеки Python.

## Функции и настройки

| Параметр | Значение | По умолчанию |
|---|---|---|
| `--package ИМЯ` | имя анализируемого пакета | обязательный |
| `--repository АДРЕС` | URL файла `Packages` или `Packages.gz`; в тестовом режиме путь к файлу | обязательный |
| `--test-mode` | режим работы с тестовым репозиторием | выключен |
| `--output ФАЙЛ` | имя файла с изображением графа, `.svg` | `graph.svg` |
| `--max-depth ЧИСЛО` | максимальная глубина анализа | `10` |
| `--filter ТЕКСТ` | исключить пакеты, имя которых содержит подстроку | пусто |

Каждый параметр проверяется; при ошибке программа печатает `error: ...`
и завершается с кодом 1.

### Откуда берутся данные

Файл `Packages` репозитория Ubuntu состоит из блоков по одному на пакет.
Зависимости — поля `Depends` и `Pre-Depends`. Из записи
`debconf (>= 0.5) | debconf-2.0, libc6:any` берётся `debconf` и `libc6`:
версии и архитектура отбрасываются, из альтернатив берётся первая.

### Тестовый репозиторий

Текстовый файл: пакеты называются большими латинскими буквами,
в каждой строке пакет и его зависимости. Строка с `#` — комментарий.

```
# Ромб
A: B C
B: D
C: D
D:
```

Примеры лежат в `test_repos/`: `diamond.txt`, `chain.txt`, `cycle.txt`,
`self_loop.txt`, `filter.txt`, `broken.txt`.

### Построение графа

Алгоритм DFS с рекурсией (`src/graph.py`). Глубина корня равна 0, пакеты
глубже `--max-depth` не раскрываются. Пакет с подстрокой из `--filter`
в граф не попадает. Циклы не приводят к зацикливанию: уже пройденный
пакет повторно не раскрывается, а найденные циклы выводятся отдельно.

### Исходные файлы

| Файл | Назначение |
|---|---|
| `src/main.py` | точка входа |
| `src/options.py` | параметры и их проверка |
| `src/errors.py` | тип ошибки `ToolError` |
| `src/apt_packages.py` | скачивание и разбор файла `Packages` |
| `src/test_repository.py` | разбор тестового репозитория |
| `src/graph.py` | DFS, глубина, фильтр, циклы |

## Сборка и запуск тестов

Сборка не нужна, требуется Python 3.9 или новее.

```bat
rem Windows
run.bat --package bash --repository URL
test.bat
```

```bash
# Linux, macOS
./run.sh --package bash --repository URL
python3 -m unittest discover -s tests -t . -v
```

Адрес для Ubuntu 22.04:

```
http://archive.ubuntu.com/ubuntu/dists/jammy/main/binary-amd64/Packages.gz
```

Демонстрация (файлы `.bat` и `.sh`):

- `examples/demo_options` — все параметры и ошибки в них;
- `examples/demo_direct` — прямые зависимости;
- `examples/demo_graph` — случаи работы с тестовым репозиторием;

## Примеры использования

```
$ ./run.sh --package A --repository test_repos/cycle.txt --test-mode
A -> B
B -> C
C -> A
packages: 3, dependencies: 3
cycle: A -> B -> C -> A
```
